## 📖 About This Repository

This repository contains academic assignments, presentations, and supporting study materials completed as part of the **Distributed Systems** course during the B.Tech Computer Engineering program at Pimpri Chinchwad College of Engineering, Pune.

It serves as a centralized collection of coursework and academic documentation covering distributed computing concepts, system architectures, communication mechanisms, and related technologies.

The repository includes five assignments and two presentation documents prepared as part of the academic curriculum.

---

## 🎯 Objectives

- Understand the fundamentals of distributed systems.
- Explore distributed computing architectures.
- Study communication and coordination between distributed components.
- Understand distributed data processing.
- Explore resource sharing and distributed services.
- Study reliability, scalability, and fault tolerance.
- Understand the challenges involved in designing distributed applications.
